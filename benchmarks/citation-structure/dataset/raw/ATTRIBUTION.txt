Files in this directory
-----------------------
opinions.csv  (4,151 rows)
    One row per court opinion retained in the build. Columns:
    id, cluster_id, plain_text.
    id is prefixed "op...", cluster_id is prefixed "cl...".
    plain_text has been REDACTED (see "Modifications" below) and
    truncated to a fixed character budget.

opinion_clusters.csv  (4,355 rows)
    One row per opinion cluster (a cluster groups the opinions issued
    together in a single decision). Columns: id, date_filed, case_name,
    case_name_short, docket_id, precedential_status, blocked.
    id is prefixed "cl...", docket_id is prefixed "dk...".

citation_edges.csv  (5,792 rows)
    The citation edges internal to this collection: one row per
    (citing opinion, cited opinion) pair where BOTH endpoints are
    present in opinions.csv. Columns: citing_opinion_id,
    cited_opinion_id.

build_meta.json
    Counts recorded at build time, including how many opinions were
    matched, how many citation edges were found, and the connected
    component structure of the resulting citation subgraph.

Modifications made to the source material
-----------------------------------------
The raw opinion text was transformed before packaging. These changes are
deliberate and are what make the task solvable only by reading the
substance of the opinions:

1. REPORTER CITATIONS REMOVED. Strings matching United States reporter
   citation patterns (e.g. "410 U.S. 113", "347 F.3d 572", "123 S. Ct.
   45") were replaced with a placeholder. Without this, the task would
   reduce to a regular-expression extraction exercise rather than a
   reading task.

2. CASE NAMES REMOVED. Party-name strings of the form "X v. Y" drawn
   from the case_name field of the clusters table were replaced with a
   placeholder wherever they appeared in the body text, for the same
   reason.

3. CONTROL CHARACTERS NORMALISED. Form feeds (\x0c), lone carriage
   returns, and other stray control characters present in the source
   scans were collapsed to ordinary whitespace so the files parse as
   clean UTF-8 delimited data.

4. IDENTIFIERS PREFIXED. The numeric CourtListener database identifiers
   were prefixed with a short letter tag ("op", "cl", "dk") so that they
   are unambiguously categorical rather than numeric quantities.

5. TEXT TRUNCATED. Opinion bodies were truncated to a fixed character
   budget to keep the package to a workable size.

The redaction is verified at build time: the shipped split contains zero
surviving reporter citations. See dataset/public/dataset_stats.json,
field "leak_scan".

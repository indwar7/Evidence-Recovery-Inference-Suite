You are acting as an independent competition review committee.

Review the following machine learning challenge exactly as if you have never seen it before.

Evaluate it using objective criteria only.

# Evaluation

## 1. Originality

Identify:

- Existing Kaggle competitions that are similar.
- Existing academic papers that are similar.
- Existing benchmarks that are similar.
- Existing datasets that are similar.

Explain exactly why they are similar.

Then estimate:

- Originality (1–10)

Justify every point deducted.

---

## 2. Task Formulation

Determine whether the task is genuinely different or merely a variation of:

- classification
- regression
- ranking
- retrieval
- OCR
- segmentation
- captioning
- sequence prediction
- information extraction

If it is merely a variation, explain why.

---

## 3. Dataset

Evaluate

- uniqueness
- realism
- information leakage
- shortcut opportunities
- ambiguity
- balance
- reproducibility

Suggest improvements.

---

## 4. Metric

Determine whether the evaluation metric actually measures the intended capability.

Identify weaknesses or exploitable cases.

---

## 5. Difficulty

Would experienced ML practitioners find this benchmark interesting?

Would a trivial heuristic perform well?

Would an LLM baseline perform well?

Explain why.

---

## 6. Scientific Value

Does this benchmark measure a meaningful capability?

Would it be useful for future research?

Would it likely be cited?

Explain.

---

## 7. Final Review

Provide:

Strengths

Weaknesses

Reviewer concerns

Acceptance recommendation

Major revisions required

Minor revisions required

If you would reject the challenge, explain exactly what should be redesigned rather than suggesting superficial changes.
